# 💼 Java Payroll System

A simple **Payroll Management System** built in **Java** that automates employee salary calculations, deductions, and report generation.  
This project demonstrates **Object-Oriented Programming (OOP)** concepts such as **inheritance, polymorphism, abstraction, and encapsulation**, along with file handling and database integration (optional).

---

## ✨ Features
- ➕ Add, update, and remove employee records  
- 💰 Calculate salaries based on working hours 
- 📄 Generate payslips for employees  
---

## 🛠️ Tech Stack
- Language: Java  
- IDE: IntelliJ IDEA
